보청기 정부지원금 5년 1회 131만원

청각장애 등록자 대상 · 만 18세 이하 양측은 262만원

핵심: 청각장애 등록 + 5년 내구연한 + 등록 모델 구입 → 최대 131만원 환급.

지원 금액

구분지원 합계
일반117만 9천원
차상위계층131만원
기초생활수급자131만원
만 18세 이하 (양측)최대 262만원

신청 절차 5단계

  • ① 이비인후과 진단 — 청각장애 진단서 발급
  • ② 주민센터 등록 — 청각장애 복지카드
  • ③ 보장구 처방전 ⭐ — 가장 중요한 단계
  • ④ 등록 모델 구입 — 처방전 후에만 구입
  • ⑤ 검수·청구 — 환급 신청
❗ 가장 많은 실수: 보청기를 먼저 사면 1원도 못 받습니다. 반드시 처방전부터 받으세요.
⭐ 자주 찾는 · 정부 지원

인공와우 건강보험 적용 · 본인부담 약 400만원

청력 70dB+ · 성인 단측 / 소아 양측

핵심: 청력 70dB 초과 + 보청기 시도 후 인공와우 수술 시 건강보험 적용. 본인부담 20%.

성인 vs 소아 조건

  • 소아 (만 1~18세): 양측 인공와우 가능 · 보청기 3개월 시도 후
  • 성인 (만 19세+): 단측 원칙 · 분실 시 추가 1개 가능 · 문장인식 50% 미만

본인부담 시뮬레이션

  • 이식기 가격 (한쪽): 약 2,100~2,300만원
  • 건강보험 적용 (80%): ~1,840만원 지원
  • 본인부담 (20%): ~460만원
  • 본인부담상한제 적용 시: 약 400만원까지 (분당서울대병원 자료)

※ 비급여·재활·외부장치 별도. 정확 견적은 수술 예정 병원 사회사업실 문의.

⚠ 본인부담 더 줄이는 방법: 사단법인·재단 후원 4곳에서 추가 지원 가능. 아래 「사단법인·재단 후원」 섹션 참고.

① 사랑의달팽이재단 (가장 인기)

  • 본인부담금 전액 + 언어재활 400만원 / 급여 미적용 시 수술비 최대 1,000만원
  • 교보생명 협력 · 연중 상시 신청
  • 사이트: soree119.com

② 삼성인공와우

  • 4년 통합 패키지 (수술 + 언어재활 + 음악교육)
  • 삼성서울병원 + 삼성전자 + 명지대 협업
  • 누적 수혜: 약 120명

③ KT 소리찾기 (일반)

  • 매년 시기 변동 (2024.11 / 2025.04)
  • 2026.05 현재 미공고 — 청생원 공지 확인 필요

국가유공자·참전유공자·고엽제·5·18 민주유공자

① 국가보훈부 보훈병원 (전국 6개)

  • 서울 · 부산 · 광주 · 대구 · 대전 · 인천
  • 청각장애 인정 시 무상 또는 자부담 보청기 지원
  • 시그니아 = 중앙보훈병원 공식 브랜드
  • 2023.06.05 보훈처 → 국가보훈부 승격

② 「국가영웅 KT소리찾기」

  • 대상: 60세 이상 참전유공자·배우자
  • 협력: 국가보훈부 + KT + 세브란스/제주대/전남대
  • 보청기 맞춤 처방 + 인공와우 검토

📞 신청 안내: 보훈지청 또는 보훈병원 청각센터 직접 문의 / 국가보훈부 대표 1577-0606

💰 매년 환급 · 세제 혜택

매년 받는 보너스 — 세제 3가지

의료비 공제 + 200만원 추가공제 + VAT 면세

3가지 혜택 (동시 적용 가능)

  • ① 의료비 세액공제 (한도 X): 장애인 의료비는 한도 없이 전액 공제 대상. 보청기·인공와우 구입비, 진료비, 재활비 모두 포함.
  • ② 장애인 추가공제 연 200만원: 본인 또는 부양가족 청각장애인이면 매년 200만원 추가 인적공제. 자녀가 부모님 부양 시도 적용.
  • ③ 부가가치세 면세: 보청기는 면세 의료기기 (VAT 0%). 가격에서 자동 반영.

신청 시기

  • 1월 연말정산 (직장인) — 회사에 의료비 영수증·증명 서류 제출
  • 5월 종합소득세 신고 (자영업자·프리랜서) — 홈택스 직접 신고
